# 🏦 Loan Approval Prediction

## 📌 Project Overview
This project predicts whether a loan application will be approved using Machine Learning. It is built using Python and a Decision Tree Classification model.

## 🚀 Features
- Loan Approval Prediction
- Data Preprocessing
- Feature Scaling
- Decision Tree Model
- User-friendly Streamlit Web App

## 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Streamlit
- Pickle

## 📂 Project Structure
```
Loan-Approval-Prediction/
│
├── app.py
├── train_model.py
├── loan_approval.xlsx
├── loan_model.pkl
├── scaler.pkl
├── requirements.txt
└── README.md
```

## ▶️ How to Run

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
streamlit run app.py
```
